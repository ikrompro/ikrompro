# Ikrom Igamberdiyev

**Senior Data & AI Engineer · 12+ years · Data platforms, MLOps, GenAI**

New York, NY · US citizen · Open to remote roles

Senior data and AI engineer with 12+ years designing data platforms and ML systems for financial services. At Bank of America I build multi-cloud warehouses on Snowflake, Redshift, and BigQuery and production pipelines in Azure Data Factory, Databricks, and Airflow for model training, inference, and regulatory reporting, with MLOps on MLflow, Databricks ML, and SageMaker and governance in Collibra and Azure Purview. At MarketAxess I delivered batch and streaming ML platforms for trading, pricing, and risk data, using Kafka, Spark, and FastAPI on Snowflake, Redshift, and Synapse. At JPMorgan Chase I developed SQL Server data marts, SSIS ETL, and SSRS reports for financial reporting.
